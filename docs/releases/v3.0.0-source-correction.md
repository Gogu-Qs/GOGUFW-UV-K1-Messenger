# GOGUFW 3.0.0 source correction

The GOGUFW 3.0.0 release published on 2026-10-08 contained the correct
firmware binary and companion files, but its Git tag was created before the
matching source tree was committed. As a result, GitHub initially showed the
older 2.3.3 source for the `v3.0.0` tag.

The complete 3.0.0 source tree was recovered from the original release build
snapshot and verified by rebuilding it. The rebuilt multiboot image has the
same 120,828-byte size as the published image. A byte comparison found only
six differing bytes, all belonging to the embedded build date and time; the
program and data bytes otherwise match.

The `v3.0.0` tag was corrected to point to the recovered source commit. The
previously published firmware binary was not replaced or modified.
