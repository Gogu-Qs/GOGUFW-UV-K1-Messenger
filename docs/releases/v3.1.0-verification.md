# GOGUFW 3.1.0 release verification

The `v3.1.0` tag is the canonical source for this release. The firmware, CHIRP
module, Search app, APRS Edit app and explicit source archive attached to the
GitHub release are all produced from that tag.

Release checks:

- clean Fusion configure and build from the tagged checkout;
- firmware version string and embedded Git commit checked against the tag;
- multiboot layout/isolation check completed by the normal build;
- Search and APRS Edit rebuilt from the same checkout and validated by the app
  packer (header, ABI/API requirement, code size and CRC);
- host-side Messenger memory smoke tests run;
- release asset SHA-256 checksums published with the release notes;
- `main` and `v3.1.0` verified to resolve to the same commit after upload.

The earlier `v3.0.0` tag remains available as the preserved 3.0.0 source line.
